# 项目启动指南

## 项目概述

这是一个基于 React + Express + MySQL 的中文文本标注与可视化平台，用于对中文文本进行实体标注、关系标注，并提供多种可视化展示方式。

## 技术栈

- **前端**: React 19 + Vite + Tailwind CSS + React Router
- **后端**: Node.js + Express + MySQL2
- **AI服务**: Python
- **分词服务**: Python

## 目录结构

```
T3-iAnctChinese/
├── backend/
│   └── server/
│       ├── AI/            # AI服务
│       ├── seg/           # 分词服务
│       └── user/          # 用户管理后端
└── frontend/              # 前端应用
```

## 环境准备

### 1. 安装 Node.js

- 推荐版本: 18.x 或 20.x
- 下载地址: https://nodejs.org/
- 验证安装: `node -v` 和 `npm -v`

### 2. 安装 Python

- 推荐版本: 3.8+  
- 下载地址: https://www.python.org/
- 验证安装: `python --version` 或 `python3 --version`

### 3. 安装 MySQL

- 推荐版本: 8.0+
- 下载地址: https://dev.mysql.com/downloads/
- 验证安装: `mysql -u root -p`

## 数据库设置

### 1. 创建数据库

1. 登录 MySQL:
   ```bash
   mysql -u root -p
   ```

2. 创建数据库:
   ```sql
   CREATE DATABASE ianct_chinese_user DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. 验证数据库创建:
   ```sql
   SHOW DATABASES;
   ```
   应该能看到 `ianct_chinese_user` 数据库

### 2. 配置数据库连接

1. 进入后端用户服务目录:
   ```bash
   cd backend/server/user
   ```

2. 创建 `.env` 文件:
   ```bash
   copy .env.example .env  # Windows
   # 或
   cp .env.example .env    # Linux/Mac
   ```

3. 编辑 `.env` 文件，配置数据库连接信息:
   ```env
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=your_mysql_password
   DB_NAME=ianct_chinese_user
   ```

   > 注意: 如果使用默认的MySQL密码 `3147`，可以跳过此步骤

## 启动项目

### 方式一: 分别启动各个服务

#### 1. 启动后端用户服务

```bash
cd backend/server/user
npm start
```

预期输出:
```
✅ MySQL 数据库连接成功
✅ 数据库初始化完成
Server is running on port 5002
```

#### 2. 启动AI服务

```bash
cd backend/server/AI
python ai.py
```

预期输出:
```
AI Server is running on port 5004
```

#### 3. 启动分词服务

```bash
cd backend/server/seg
python seg_server.py
```

预期输出:
```
Segmentation Server is running on port 5001
```

#### 4. 启动前端

```bash
cd frontend
npm run start
```

预期输出:
```
VITE v5.4.10  ready in 2000 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

### 方式二: 同时启动所有服务

前端目录提供了一个脚本，可以同时启动所有服务:

```bash
cd frontend
npm run start:services
```

预期输出:
```
[user] ✅ MySQL 数据库连接成功
[user] ✅ 数据库初始化完成
[user] Server is running on port 5002
[ai] AI Server is running on port 5004
[seg] Segmentation Server is running on port 5001
[user] Connected to MySQL database: ianct_chinese_user
```

## 常见问题与解决方案

### 1. 数据库连接失败

**问题**: `❌ MySQL 数据库连接失败: Access denied for user 'root'@'localhost' (using password: YES)`

**解决方案**:
- 检查 `.env` 文件中的数据库密码是否正确
- 确保 MySQL 服务正在运行
- 确保 MySQL 用户具有创建和修改表的权限

### 2. 端口被占用

**问题**: `Error: listen EADDRINUSE: address already in use :::3001`

**解决方案**:
- 终止占用该端口的进程
- 或修改配置文件中的端口号

### 3. 依赖安装失败

**问题**: `npm install` 或 `pip install` 失败

**解决方案**:
- 确保网络连接正常
- 尝试使用国内镜像源
  - npm: `npm install --registry=https://registry.npmmirror.com`
  - pip: `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

### 4. 前端无法连接后端

**问题**: 前端控制台显示 `Failed to fetch` 或 `Network Error`

**解决方案**:
- 确保后端服务正在运行
- 检查前端服务中的API配置是否正确
- 检查浏览器控制台的网络请求，确认请求地址是否正确

## 开发说明

### 代码结构

#### 前端 (`frontend/src`)
- `components/`: 组件目录
- `pages/`: 页面目录
- `services/`: API服务目录
- `hooks/`: 自定义Hooks
- `styles/`: 样式文件
- `utils/`: 工具函数

#### 后端 (`backend/server/user`)
- `config/`: 配置文件
- `middleware/`: 中间件
- `migrations/`: 数据库迁移脚本
- `models/`: 数据模型
- `routes/`: 路由定义
- `user-server.js`: 服务入口

### 开发命令

#### 前端
- `npm run start`: 启动开发服务器
- `npm run build`: 构建生产版本
- `npm run test`: 运行测试

#### 后端
- `npm start`: 启动后端服务
- `npm run dev`: 使用 nodemon 启动开发模式

## 部署说明

### 生产环境部署

1. **前端部署**:
   - 构建生产版本: `npm run build`
   - 将 `dist` 目录部署到 Nginx 或其他静态文件服务器

2. **后端部署**:
   - 使用 PM2 管理 Node.js 进程
   - 配置环境变量
   - 确保数据库连接正确

3. **AI服务和分词服务**:
   - 使用 Supervisor 或其他进程管理工具
   - 配置环境变量

### 环境变量配置

生产环境中，建议使用环境变量管理敏感信息，如数据库密码、API密钥等。
